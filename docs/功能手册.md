# 功能手册

> 面向使用者的完整操作指南。所有数据仅存于本机浏览器，首次启动会自动生成四本示例书供体验。

## 一、书架

- **导入**：点击「导入书籍」按钮，或直接把文件**拖入页面任意位置**（出现朱砂色虚线投放区）。一次可多选；`.zip` 会自动嗅探为 EPUB 或 CBZ。
- **继续阅读**：首行横卡展示最近阅读的书与实时进度条。
- **封面墙**：悬停封面浮起并显示操作条——阅读 / 转换 / 笔记数 / 打包导出 / 移除。
- **移除**：级联删除该书文件、批注、书签与进度（有确认弹窗）。
- 顶部统计栏实时显示藏书数、总字数与批注总数。

## 二、阅读器

### 工具栏（自左向右）

| 按钮 | 功能 |
| --- | --- |
| ‹ › | 上一章 / 下一章（PDF、CBZ 为翻页） |
| 目录 | 章节抽屉，点击直达 |
| 搜索 | 全文搜索，当前章节内高亮并可逐处跳转 |
| 书签 | 收藏当前位置（自动携带章节/页号标签） |
| A− / A+ | 字号 14–26px |
| 行距 | 1.4 / 1.6 / 1.85 / 2.1 四档 |
| 双栏 / 滚动 | 分页模式 ⇄ 滚动模式切换 |
| 缩放 | 50%–200%（影响列宽与版面） |
| 主题 | 纸白 / 青瓷 / 夜读三色 |
| 全屏 | 沉浸式阅读（Esc 退出） |

### 键盘快捷键

| 按键 | 动作 |
| --- | --- |
| `←` / `→` | 上一页 / 下一页（或上/下一章） |
| `Esc` | 退出全屏 / 关闭弹层 |

### 批注操作

1. 用鼠标选中任意文字 → 光标上方浮出工具条；
2. 先点**颜色**（松烟绿 / 朱砂 / 鎏金 / 黛蓝），再点**类型**（高亮 / 下划线 / 删除线 / 批注）；
3. 「批注」类型会立即打开编辑框，可写随文札记；
4. 点击正文中任意批注 → 弹层可改色、补写批注或删除；
5. 批注随书持久化，关闭重开自动还原，且可在「笔记」页一键回跳（目标处闪烁提示）。

> 提示：分页模式下批注若落在当前页之外，回跳时会先进入滚动视图定位。

### PDF 与漫画

- **PDF**：矢量 Canvas 渲染，随缩放重绘；底部页码输入框直达任意页，进度按页记录。
- **CBZ 漫画**：横向长卷滚动浏览，左右箭头逐页，页码悬浮显示。
- **SVG / 图片**：等比缩放查看。

## 三、转换器

1. **选源**：本地文件，或从书库下拉直接选择；
2. **选目标**：按钮组随源格式动态列出可用目标（见 README 支持矩阵）；
3. **开始转换**：阶段文案实时播报（解析 → 重排/光栅化 → 完成）；
4. **成果处理**：下载 / 存回书架（成为新书继续阅读）/ 随书打包导出；成果同时暂存于右侧「会话导出」列表，关闭标签页后清空。

**特别说明**

- 文本类 → PDF 采用离屏光栅化排版，**原生支持中文**，无字体嵌入问题；
- PDF → TXT 仅能提取含文本层的 PDF（扫描件无文本层时输出为空属正常）；
- CBZ → PDF 画册按首图比例自适应页面方向，单次上限 200 页；
- MOBI/AZW3 仅支持未加密文件，DRM 文件会被明确拒绝。

## 四、编辑器

三个页签共用同一文稿上下文：

### 富文本
- 工具条：撤销/重做、段落级别（正文/标题一~三/引文）、加粗/斜体/下划线/删除线、列表、插入链接（选区 + 弹层输入 URL）、插入图片（转 dataURL 内嵌）、插入 3×3 表格、清除格式；
- 底部实时字数统计；
- 「从书库载入…」可将 EPUB / DOCX / MD / TXT / HTML / FB2 / SVG 的正文拉进编辑器续写。

### HTML 源码
- 左栏深色代码区直接编辑，右栏 iframe 沙箱实时预览（`sandbox` 隔离，脚本不执行）；
- 与富文本页签**双向同源**：切换页签即同步。

### SVG 画板
- 工具：选择/移动、矩形、椭圆、直线、自由画笔、文字（双击修改）；
- 属性：填充色、描边色、线宽滑杆，选中后可编辑；
- 图层：置顶/置底/复制/删除/撤销/清空，网格与深色画布开关；
- 输出：导出 `.svg`、复制 SVG 代码、存回书架（成为可阅读的 SVG 书）；
- 从书库载入 SVG 时，原图作为不可编辑底稿保留在画布底层。

### 另存为
HTML / DOCX / EPUB 三种格式一键下载；「存回书架」将当前文稿以 HTML 书身份加入书库。

## 五、笔记中心

- 顶部筛选：全部 / 高亮 / 下划线 / 删除线 / 批注 / 书签（带计数）+ 书籍下拉 + 关键词搜索（同时匹配原文、批注、章节名）；
- 批注卡片悬停出现：**回跳原文**（进入阅读器并闪烁定位）、**编辑批注**、删除；
- 书签卡片可**回到此处**（恢复章节与百分比/页号）或删除。

## 六、导出 ZIP

1. 选择书籍（从书架封面「打包」按钮进入时自动选定该书）；
2. 勾选打包内容：原书文件 / 笔记 JSON / 笔记 Markdown / 笔记 CSV / 书签 / 阅读进度 / 元数据与封面 / 会话转换成果；
3. 右侧**实时预览压缩包目录树**（未勾选项灰色删除线）；
4. 点击「生成并下载 ZIP」，得到 `《书名》_墨阁导出.zip`，内部结构：

```
《书名》/
├── 原书/            原始格式文件
├── 笔记/            annotations.json · notes.md · annotations.csv
├── 书签/            bookmarks.json · bookmarks.md
├── 阅读进度/        progress.json
├── 元数据/          metadata.json · cover.jpg
└── 转换文件/        本次会话导出的全部转换成果
```

`annotations.json` 保留字符偏移坐标，配合原书可在重新导入后精确还原批注位置。

## 七、已知限制

| 限制 | 说明与建议 |
| --- | --- |
| 加密 MOBI/AZW3 | DRM 文件无法解析，请先用 Calibre 去除限制（仅限合法持有） |
| 扫描版 PDF | 无文本层，搜索/提取文本为空；阅读渲染不受影响 |
| 超大文件 | 建议单文件 < 50MB；更大的 CBZ 可分批转换 |
| EPUB 内嵌字体/复杂 CSS | 统一应用阅读主题排版，原书样式仅保留结构语义 |
| 会话转换成果 | 仅存内存，刷新页面后需重新转换 |
| 浏览器兼容 | 推荐 Chrome / Edge 最新版（IndexedDB、CSS 多列、File API 依赖） |
