# 部署指南

> 覆盖三种场景：Windows 本地开发/使用、局域网共享、GitHub Pages 公网静态托管。

## 一、Windows 本地部署（推荐日常使用）

### 1. 安装 Node.js

- 下载 LTS 版：<https://nodejs.org/>（建议 v20+），安装时勾选 "Add to PATH"；
- 验证：`node -v` 与 `npm -v` 均有输出。

### 2. 获取代码并安装

```powershell
# 方式一：从 GitHub 克隆
git clone https://github.com/你的用户名/bookviewer-pro.git
cd bookviewer-pro

# 方式二：下载 Release ZIP 解压后进入目录

npm install
```

> 国内网络若安装缓慢，可临时使用镜像：`npm install --registry=https://registry.npmmirror.com`

### 3. 两种运行方式

**开发模式（带热更新）**

```powershell
npm run dev
# 浏览器打开 http://localhost:5173
```

**生产模式（推荐长期使用）**

```powershell
npm run build          # 生成 dist/
npx serve dist -l 4173 # 任意静态服务器均可
# 浏览器打开 http://localhost:4173
```

生产模式资源经过压缩分包，首屏更快。可将上述命令保存为 `启动墨阁.bat`：

```bat
@echo off
cd /d %~dp0
start http://localhost:4173
npx serve dist -l 4173
```

双击即开。

### 4. 数据位置与备份

- 全部数据存于浏览器 IndexedDB（Chrome 路径：`%LOCALAPPDATA%\Google\Chrome\User Data\Default\IndexedDB`）；
- **备份**：用应用内「导出 ZIP」把书与笔记打包；**迁移**：新环境重新导入原书，批注坐标文件（`annotations.json`）可用于还原；
- 更换浏览器或清除站点数据会清空书库，请提前导出。

## 二、局域网共享（多人/多设备访问）

Vite dev server 默认只监听本机。局域网共享推荐生产模式：

```powershell
npm run build
npx serve dist -l 4173 --cors
ipconfig    # 查看本机 IPv4，如 192.168.1.20
```

其他设备访问 `http://192.168.1.20:4173`。若无法访问：

1. Windows 防火墙放行 4173 端口（控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP 4173）；
2. 确认设备在同一子网，且网络类型为「专用网络」。

> 每位访问者的数据各自存于**自己浏览器**的 IndexedDB，互不影响——这正是纯前端架构的特性。

## 三、GitHub Pages 公网托管

仓库已内置 `.github/workflows/deploy.yml`：

1. 推送代码到 `main` 分支（见 [GitHub上传步骤](GitHub上传步骤.md)）；
2. 仓库 **Settings → Pages → Source** 选择 **GitHub Actions**；
3. 推送触发 workflow：`npm ci` → `vite build --base=./` → 上传 `dist` → 部署；
4. 约 2 分钟后访问 `https://你的用户名.github.io/bookviewer-pro/`。

**注意事项**

- `--base=./` 由 workflow 注入，保证 Pages 子路径下资源相对引用正确；本地 `npm run build` 不受影响；
- Pages 仅托管静态资源，应用逻辑全在浏览器端，**访客数据只存于访客自己的浏览器**，无服务端、无数据库成本；
- 私有仓库需 GitHub Pro 才能用 Pages；公开仓库免费。

### 手动部署（不用 Actions 的替代方案）

```powershell
npx vite build --base=./
npx gh-pages -d dist    # 需先 npm i -D gh-pages
```

在仓库 Settings → Pages 将 Source 改为 `gh-pages` 分支即可。

## 四、桌面化（可选进阶）

如需独立窗口体验，可套一层 Electron：

```powershell
npm i -D electron electron-builder
```

新建 `electron/main.cjs` 加载 `dist/index.html`（`file://` 协议需将 build base 设为 `./`），`electron-builder` 打包为 Windows 安装程序。应用无任何服务端依赖，Electron 化零改造。

## 五、运维检查清单

- [ ] Node ≥ 18，`npm run build` 无错误；
- [ ] 首开自动构建示例书库成功（书架出现 4 本书）；
- [ ] 导入一本 EPUB 可分页阅读、批注可还原；
- [ ] 转换 EPUB → PDF 成功下载且中文正常；
- [ ] 导出 ZIP 目录结构完整；
- [ ] （Pages）workflow 绿勾，线上可访问。
