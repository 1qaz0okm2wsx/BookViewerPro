# BookViewerPro

A modern local reader for text files and PDFs.

## Features
- Library of imported books and sample content
- Text reading with chapter navigation
- PDF import and page preview
- Bookmarks and reading progress
- Searching within the current chapter
- Personal note panel
- Dark mode and adjustable font size

## Run locally
```bash
npm install
npm run dev
```

Then open the local Vite URL in your browser.

## Notes
This project is designed as a lightweight reading app prototype powered by React + Vite, with PDF support via pdf.js.
